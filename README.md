# Cont Bot (Con_bot)

Telegram-бот месячного курса: расписание Т1–Т4, баллы, прогрессия по неделям, стихии по знаку зодиака, сбор слов и аналитика.

## Данные (JSON)

- `data/tasks.json` — библиотеки Т2 (art, life_themes, choice_sets, final), Т3, Т4
- `data/schedule_15_25.json`, `schedule_25_35.json`, `data/schedule_35_plus.json` — расписание на 30 дней по возрасту

После даты рождения бот выставляет `age_group` (15-25 / 25-35 / 35+), `zodiac_sign`, `element` (fire/earth/air/water).

## Курс (Т1–Т4)

- **Т1 утро** 9:00–10:00, **Т1 вечер** 21:00–22:00 (баллы по 1)
- **Т2** 12:00–21:00 (2 балла), **Т3** случайное 14:00–18:00 до 22:00 (3), **Т4** случайное 10:00–20:00, окно 1 ч (4)
- Неделя 1: без утреннего Т1 в этот день **Т2 не назначается**
- Неделя 2+: кнопка **«Пропустить»**; слово после задания не обязательно (неделя ≥ 2)
- Неделя 3+: `/set_time t2|t3|t4 ЧЧ:ММ` — предпочтительное время
- Неделя 4: выбор из двух вариантов Т2/Т3 — **в разработке**

Список заданий: команда `/plan` (текст из `data/tasks.json`). Авто-рассылка по времени в `main` отключена.

## Слова и отчёты

- Кластерный словарь, `user_words`, еженедельный отчёт (воскресенье 20:00), API `/api/word`, `/api/report`
- Админ: `ADMIN_IDS` в `.env`, команды `/addword`, `/stats`, `/review`, `/recalc`

## SQLite

Таблицы: `users`, `user_scheduled_tasks`, `user_settings`, `user_words`, `word_dict`, `user_profile`. (План v1 / `task_templates` удалён из схемы для новых установок; в старой БД старые таблицы могли остаться.)

## Запуск

```bash
pip install -r requirements.txt
python -m app.main
```

`.env`: `BOT_TOKEN`, `TIMEZONE`, `ADMIN_IDS`, `API_PORT`.
